- katex pinned to 0.16.47, not the 0.18.7 'latest' tag: rehype-katex 7.0.1 (latest) declares a katex ^0.16.0 dependency. 0.16.47 is the newest release inside the range the current rehype-katex supports.
- Zod 4 supplies z.toJSONSchema() natively, so no separate zod-to-json-schema dependency is used for C01. Frontmatter is parsed with the yaml package plus an explicit delimiter split rather than gray-matter, so Markdown is never handed to a templating engine.
- The docs plugin is mounted at routeBasePath '/' rather than 'concepts'. Docusaurus resolves frontmatter 'slug' relative to routeBasePath, so the frozen canonical slug '/concepts/<name>' produced '/concepts/concepts/<name>' under routeBasePath 'concepts'. Mounting at the site root reproduces the frozen slugs exactly while src/pages still owns /, /search, /explore, /ask and /about (verified: each route renders its own h1).
- Two enumerations are not spelled out in the runbook and were derived rather than invented freely. sources[].supports is the kebab-cased set of the ten substantive Tier 1 section headings from §4.1 (the example value 'uses-and-applicability' matches '## Uses and applicability' exactly); 'sources' and 'prerequisites-and-next-connections' are excluded because they are navigational rather than claims. sources[].source_kind extends the example value 'authoritative-secondary' with primary-research, preprint, reference-documentation, lecture-or-course, implementation and dataset-or-benchmark.
- Category paths must begin with one of the three atlas areas named in the product brief — Artificial Intelligence, Mathematics, Programming — so that F04's 'three top-level atlas categories' is a validated fact rather than a convention.
- Raw HTML in canonical Markdown is captured by the loader as data and rejected by validation. Docusaurus parses canonical .md as CommonMark, which would otherwise pass raw HTML straight through to the reader.
- URL reachability at 2026-09-16: 18 of 19 source URLs returned HTTP 200. https://ieeexplore.ieee.org/document/726791 (the LeNet-5 paper) returns HTTP 202 rather than 200 — a response, not a failure, but the page body was not fetched, so reachability there is weaker evidence than for the others. Reachability was never treated as evidence that a source supports a claim; each sources[].supports list names only sections the source materially supports.

The runbook subordinates length to correctness in the same sentence ('correctness is more important than length'), and the twelve-section Tier 1 template leaves roughly 80-100 words per section at this length.
